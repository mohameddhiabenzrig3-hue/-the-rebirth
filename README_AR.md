# THE REBIRTH — Android (Python + Kivy + SQLite)

## ما تتضمنه الحزمة
- تطبيق Android مبني باستخدام Python/Kivy.
- قاعدة SQLite محلية تنشأ تلقائياً عند أول تشغيل.
- إدارة العادات وتسجيل إنجازها اليومي وسلاسل الالتزام.
- المهمات والأولويات والإنجاز.
- الأهداف والتقدم.
- بناء الروتينات.
- مؤقت تركيز وسجل الجلسات.
- أبعاد الحياة وتقييمها.
- التحديات.
- المراجعة الذاتية.
- خطط مواجهة العادات غير المرغوبة.
- الأداء اليومي والتقارير.
- الملف الشخصي والميثاق.
- الملاحظات.
- فهرس المنظومات الثلاثين.
- نسخ احتياطي لقاعدة SQLite واستعادتها.
- Workflow لبناء APK عبر GitHub Actions.

## بناء APK من الهاتف عبر GitHub
1. حمّل ZIP وفك ضغطه.
2. أنشئ مستودعاً عاماً أو خاصاً جديداً في GitHub باسم `the-rebirth`.
3. ارفع محتويات المجلد إلى جذر المستودع.
4. افتح تبويب Actions وفعّل Actions إن طُلب.
5. شغّل `Build THE REBIRTH APK` بواسطة Run workflow.
6. عند نجاح التشغيل، افتح صفحة التشغيل وحمّل Artifact المسمى `THE-REBIRTH-Android-APK`.
7. فك ضغط Artifact وثبّت ملف APK على هاتف Android.

## ملاحظات مهمة وصريحة
- هذه نسخة تطبيق محلية قابلة للتطوير، وليست شهادة خلو مطلقة من الأخطاء على كل هاتف.
- المنظومات الثلاثون موجودة في الفهرس، وقد تم تنفيذ وظائف تشغيلية أساسية لكثير منها داخل التطبيق. الأنظمة المتقدمة مثل الإشعارات المجدولة، التحليلات التكيفية العميقة، مزامنة الأجهزة، والتكاملات الخارجية تحتاج تطويراً واختبارات إضافية.
- لم يتم إنشاء APK داخل بيئة إعداد الحزمة؛ ملف APK يجب أن ينتج من تشغيل GitHub Actions بنجاح.
- البيانات محلية في مساحة التطبيق. احفظ نسخاً احتياطية دورياً.
- لا يوجد تسجيل دخول أو رفع بيانات إلى خادم.
